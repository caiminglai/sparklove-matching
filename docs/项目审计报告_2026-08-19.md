## 四、可优化项

### 4.1 ESLint 配置不兼容（潜在问题）

| 文件 | 问题 |
|------|------|
| `app/.eslintrc.json` | 使用 legacy 格式（`.eslintrc.*`），但 `package.json` 安装了 eslint 9.x，默认要求 flat config（`eslint.config.js`）。eslint 9.x 默认不再读取 `.eslintrc.json`，`npm run lint` 可能静默跳过或报错 |
| `app/.eslintrc.json` | `ignorePatterns` 包含 `.eslintrc.cjs`，但该文件不存在 |
| `backend/` | `package.json` 有 `"lint": "eslint ."` 但**无任何 eslint 配置文件**，lint 命令无法正常工作 |

**建议**：前端迁移到 `eslint.config.js` flat config；后端补充 eslint 配置文件。

### 4.2 安全相关（审计报告已指出，仍未修复的）

| 优先级 | 问题 | 文件 | 说明 |
|--------|------|------|------|
| P0 | Token/加密密钥默认可预测 | `backend/db/index.js` | 未设环境变量时用 `'default'` 种子 |
| P0 | check-unlock 接口无需认证 | `backend/routes/contact-unlock.js` | viewerId 从 URL 参数取 |
| P0 | Auth Token 存 localStorage | `app/src/pages/LoginPage.tsx` | 可被 XSS 读取 |
| P1 | 用户列表/搜索公开访问 | `backend/server.js` | 无认证可爬取 |
| P2 | 速率限制基于内存 | `backend/server.js` | 多实例部署失效 |
| P2 | Math.random() 用于 Token | `backend/db/index.js` | 非加密安全 |

### 4.3 .gitignore 全局图片忽略

`.gitignore` 全局忽略 `*.jpg`、`*.png` 等，虽然用 `!` 例外保留了收款码图片，但这种全局忽略容易导致其他必要图片（如 README 截图、设计稿）被意外忽略。建议改为只忽略 `uploads/` 和 `data/` 下的图片。

### 4.4 前端 .env.production 与文档不一致

实际 `app/.env.production`：`VITE_API_BASE_URL=/api`（根路径部署，正确）
文档 `docs/部署运维.md` 写：`VITE_API_BASE_URL=/jzxr/api`（过时）
