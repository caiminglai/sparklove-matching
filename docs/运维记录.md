### 2.13 管理后台 `/admin` 打不开，显示"页面不存在"（2026-09-21 已修复）

现象：`https://sparklove.cn/admin` 打开是一张"页面不存在"的页面，看起来像 404；站1、站3 的后台都正常。

根因：后台页面**不在前端 React 里**，是后端 `server.js:202-233` 自己读的四个 html（`login` / `main` / `m` / `m-login`）。而前端容器的转发名单 `frontend-server.mjs:39` 只有 `/api/`、`/uploads/`、`/avatars/`，`/admin` 不在内 → 被静态服务当成"我这边找不到文件的前端路由"，回退成 `dist/index.html` → React 里当然也没有后台路由，于是渲染它自带的"页面不存在"。**HTTP 状态码从头到尾是 200，服务器并没有报 404。**

为什么以前能开：旧 Nginx 有单独的 `/admin` location 直接转 `127.0.0.1:8080`。2026-09-20 切 Caddy + 前端容器时这条规则没搬过来，`docs/部署运维.md` §3 当时把它记成"上线前必须处理"的已知缺口，一直拖到今天真踩上才修。

修复：`frontend-server.mjs:39` 加一项 `/admin/`（`isProxy` 里 `pathname === p.slice(0,-1)` 顺带覆盖了不带斜杠的 `/admin`）。

验证（本机，未重建容器，直接跑改后的 `frontend-server.mjs` 于临时端口 4101，后端指 `127.0.0.1:8080`）：

| 请求 | 改前 | 改后 |
|:---|:---|:---|
| `/admin`、`/admin/` | 200 / 2763B（首页壳） | **200 / 4368B** = 与直连 `127.0.0.1:8080/admin` 一字不差 |
| `/admin/main` | 200 / 2763B（首页壳） | **200 / 105301B** |
| `/admin/m` | 200 / 2763B（首页壳） | **200 / 3973B** |
| `/circle/123`（未知前端路由） | 回退 index.html | 回退 index.html（**前端路由零变化**） |
| `/api/admin/stats` | 401 | 401（代理不受影响） |

部署要点：这份文件**烤在 `jzxr-web` 镜像里**，改仓库不重建等于没改 → `docker compose up -d --build jzxr-web`。后端 `jzxr` 与 `postgres` 不用动。
未加 `basic_auth`：后台登录页公网可达，靠 `ADMIN_PASSWORD` + Token 保护，暴露面与迁移前 Nginx 时期一致。

## 4. 绝对禁止

以下操作在任何情况下都不允许：

- 不要在前端代码中写死 `localhost:8080` 或 `127.0.0.1:8080`
- 不要把 `ADMIN_PASSWORD` 写进前端代码
- 不要把 `node_modules` 上传到服务器（服务器上重新 `npm install`）
- 不要把 Windows 编译的 `.node` 文件上传到 Linux 服务器
- 不要在服务器上临时改代码（本地解决配置问题后再上传）
- 不要泄露项目手册中的密码信息
